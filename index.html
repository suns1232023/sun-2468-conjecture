1. Problem Definition & Counterexample

Sun's (2,4,6,8) Binomial Representation Conjecture (OEIS A306477, proposed 2019) asserts that every positive integer \(n\) can be represented as:

\[n = \binom{W}{2} + \binom{X}{4} + \binom{Y}{6} + \binom{Z}{8}, \qquad W \ge 2,\ X \ge 3,\ Y \ge 5,\ Z \ge 7.\]

Equivalently, in shifted non-negative coordinates \((w = W-2,\ x = X-3,\ y = Y-5,\ z = Z-7 \ge 0)\):

\[n = \binom{w+2}{2} + \binom{x+3}{4} + \binom{y+5}{6} + \binom{z+7}{8}, \qquad w,x,y,z \ge 0.\]

The conjecture is computationally refuted at:

\[\boxed{n^* = 896{,}315{,}812{,}331{,}399, \qquad R(n^*) = 0.}\]

This counterexample lies approximately \(448\times\) beyond the prior \(2 \times 10^{12}\) verification bound. The counterexample was originally identified through the OEIS Open research run; this repository is a downstream computational audit and formalization project.

4. Discriminant Framework

For fixed \((X,Y,Z)\), define \(m = n^* - \binom{X}{4} - \binom{Y}{6} - \binom{Z}{8}\) and \(D = 8m+1\). A valid \(W\) exists if and only if \(D = s^2\) for some odd \(s \ge 3\).

Since \(D \equiv 1 \pmod{8}\) and odd squares satisfy \(s^2 \equiv 1 \pmod{8}\), the discriminant gap \(\delta_D = D - s_0^2\) satisfies \(\delta_D \equiv 0 \pmod{8}\). Therefore \(\delta_D \ne 0 \Rightarrow |\delta_D| \ge 8\).

[COMP_VERIF] Minimum observed \(|\delta_D| = 8\) across all 2,755,643,831 triples, at \((X,Y,Z) = (6138, 22, 13)\), nearest odd root \(s_0 = 81{,}840{,}409\), relative gap \(\rho_{\min} \approx 4.89 \times 10^{-8}\). (V40.2 reported \(5.94 \times 10^{-8}\); corrected as C4.)

Note: \(\delta_D \ne 0\) for all triples is equivalent to \(R(n^*)=0\), not an independent obstruction theorem.

5. Sibling Conjecture A306462 — Structural Comparison

OEIS A306462 conjectures that every positive integer \(n\) can be represented as \(\binom{2w}{2}+\binom{x+2}{3}+\binom{y+3}{4}+\binom{z+4}{5}\) with \(w \ge 1,\ x,y,z \ge 0\).

Property (2,4,6,8) / A306477 A306462
Exponent sum \(\sum 1/k_i\) \(25/24 \approx 1.042\) \(77/60 \approx 1.283\)
Main-term exponent \(1/24 \approx 0.0417\) \(17/60 = 0.2833\ldots\) (corrected from 0.30 in V47)
\(S_{\min}\) (local density) \(\approx 0.144\) \(\approx 0.434\) [HEURISTIC]
Zeros for \(n \le 10^8\) \(R(n^*)=0\) at \(n^* \approx 8.96 \times 10^{14}\) None found [COMP_VERIF]
\(R=1\) points \(R(1)=1\) \(\{1,4,5,14,19\}\) [COMP_VERIF]

[HEURISTIC] A thicker main term (\(n^{17/60}\) vs \(n^{1/24}\)) and higher \(S_{\min}\) make zeros less plausible for A306462 than for (2,4,6,8). This is a qualitative argument, not a theorem. No conclusion for other sibling conjectures is drawn without separate computation.
